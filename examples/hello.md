# Hello, Beautiful Markdown PDF

This is the Week 1 milestone document.

The conversion pipeline right now is intentionally trivial:

1. Read this Markdown file.
2. Wrap it in an HTML shell (no parsing yet).
3. Ask Chromium to print it as a PDF.

Proper Markdown parsing, Shiki syntax highlighting, and the grayscale Minimal theme arrive in Weeks 2 through 6.
